# CS423 SOLID Team 3 - Query Module

## Project Overview

This repository contains the selected files from the **Query** module of the **greenDAO** open-source project. The files were selected for the CSE423 Software Architecture course assignment to analyze the software structure and identify opportunities for applying the SOLID principles.

## Original Repository

- **Project Name:** greenDAO
- **GitHub Repository:** https://github.com/greenrobot/greenDAO

## Selected Module

- Query Module

## Selected Files

1. AbstractQuery.java
2. Query.java
3. QueryBuilder.java
4. CountQuery.java
5. CursorQuery.java
6. DeleteQuery.java
7. LazyList.java

## Assignment Objective

The objective of this project is to analyze the selected source code files, understand their responsibilities, identify potential violations of the SOLID principles, and propose suitable refactoring approaches to improve the software architecture while preserving the existing functionality.
